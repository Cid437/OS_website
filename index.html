Operating Systems & Virtual Machines

An operating system is the core software that manages hardware and mediates every interaction between a user and a machine. This archive documents that layer directly: each case study is performed inside a virtual machine, a software-defined computer running its own OS, applications, and resources on top of a host system.

  • Managing hardware resources: CPU, memory, storage
  • Running and controlling applications and processes
  • Providing security through accounts, permissions, and policy
  • Offering a consistent interface between user and hardware

Why VirtualBox

Oracle VirtualBox provides an isolated environment for standing up multiple operating systems on a single physical machine, which is what makes this kind of lab work possible without dedicated hardware.

  • Run and compare multiple operating systems safely
  • Test server roles and configurations without production risk
  • Practice real administration workflows end to end
